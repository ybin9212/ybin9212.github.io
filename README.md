Python·SQL 기반 데이터 파이프라인과 자동화로 **글로벌 마케팅 데이터 운영**을 개선해 왔습니다.

## 제가 만드는 가치

| | |
|---|---|
| **측정 신뢰** | 집계 오류로 YoY **-93%** 로 보이던 성과를 재검증해 실제 **+52%** 로 정정 · 리포팅에서 누락되던 신규 광고 성과 **92~93%** 를 규명해 기준 재정립 · 갱신 없이 반복 제공되던 Enrichment 데이터의 **Snapshot 구조**를 검증으로 밝혀 광고주 리포팅에 반영 |
